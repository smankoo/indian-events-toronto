# Feed mock (product proposal)

Renders the proposed Instagram feed from real events: alerts, weekly roundup, coming up,
guides and features (`templates.py`), drafts "why go" lines with an LLM (`why_lines.py`),
and builds the proposal page (`build_feed.py` + `pitch_template.html`). Scratch code for
the manual phase; templates get ported into `image_generator/` once the direction is approved.
